CLI Todo


This repository contains a Command-Line Interface (CLI) Todo application built with Node.js and JavaScript. It serves as an introductory project demonstrating fundamental programming concepts and Node.js I/O handling.

Features
1. Add tasks
2. View tasks
3. Delete tasks
4. Exit the program

Installation
1. Clone the repository:
git clone https://github.com/yourusername/yourrepo.git
cd yourrepo
2. Ensure Node.js is installed.
3. Run the application:
node todo_v2.js

Learning Outcomes
JavaScript basics: arrays, functions, loops, callbacks
Node.js CLI input/output handling
Git and GitHub workflow (branches, commits, pushes)
Problem-solving and logical thinking skills
